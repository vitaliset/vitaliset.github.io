ACID: attacker-controlled input data

Para cada dado que o programa usa, a pergunta: o atacante consegue controlar isso?

Vulnerabilidade costuma ser ACID chegando a um lugar sensível sem checagem: abrir um arquivo, montar SQL, copiar para a memória.

Termo do curso Vulnerabilities 1001, OpenSecurityTraining2 (ost2.fyi/Vulns1001)

O problema

Path traversal

Vulnerável
BASE = "/uploads/" def baixar(): nome = request.args["nome"] return send_file(BASE + nome)
ACID: o atacante escolhenome = ../../etc/passwd
O servidor abre/uploads/../../etc/passwd
= /etc/passwd

Entrega um arquivo do sistema

O problema

Path traversal: a correção

Corrigido
BASE = Path("/uploads").resolve() def baixar(): nome = request.args["nome"] alvo = (BASE / nome).resolve() if not alvo.is_relative_to(BASE): abort(403) return send_file(alvo)
ACID: o atacante escolhenome = ../../etc/passwd
O servidor confere/etc/passwd
está fora de /uploads

403: pedido recusado

Big Sleep

Um agente de IA que investiga código como um pesquisador: lê, levanta hipóteses, testa e depura.

agente em ação (ilustração)
agente> objetivo: achar falhas de memória no SQLite agente> ler_codigo("trecho que processa a consulta") ↳ um índice vem da consulta SQL: é ACID ↳ não há checagem de limite antes do uso agente> hipótese: uma consulta forjada lê fora do array agente> python("gera_consulta.py") ↳ consulta de teste criada agente> debugger("sqlite3 < consulta.sql") ↳ ASan: leitura fora dos limites da memória agente> relatorio("falha confirmada, com caso de teste")

Ilustração do fluxo de trabalho, não um registro real. As ferramentas são as do agente: ler código, rodar Python, depurar, relatar.

CodeMender

Um agente de IA que corrige falhas, aplicado ao baixar():

1EntenderAcha a causa: o caminho não é validado
2CorrigirPropõe aceitar só caminhos dentro da pasta
3ValidarOutro agente testa se nada quebrou
4EnviarO patch vai para os mantenedores do projeto

A correção proposta

nome = request.args["nome"] - return send_file(BASE + nome) + alvo = (BASE / nome).resolve() + if not alvo.is_relative_to(BASE): + abort(403) + return send_file(alvo)

Se o segundo agente achar que algo quebrou, o patch volta para ser refeito.

Safe coding

C++ endurecido

E o C++ que já existe? O Google ligou checagem de limites na biblioteca padrão, em produção.
